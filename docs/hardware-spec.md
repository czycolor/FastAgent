# FastAgent 开发环境硬件方案（笔记本 + 塔式工作站）

> 版本：v0.1　日期：2026-08-25
> 状态：待采购。价格为 2026 年 8 月行情，下单前以实时渠道价为准。

## 1. 方案概述

**用途**：FastAgent 的开发测试场——本地起 vLLM/SGLang 推理服务、TEI 跑 BGE-M3/reranker、
Docker Compose 全家桶（fastagent-api + qdrant + tei + postgres + langfuse + Blazor 前端），
与公司 H20 上的约 30B 级 Qwen 模型对齐开发（见 `design.md` §2.2/§5）。

**预算**：笔记本 + 服务器合计 3 ~ 6 万元。

**两档方案**：

| 方案 | 笔记本 | 服务器 GPU | 合计 |
|---|---|---|---|
| **A（推荐）** | 微星 B3WH + 自扩 64GB（约 2.9 万） | RTX 5090D 32GB（预留双卡位） | ~6.0 ~ 6.6 万 ⚠️ 略超上限 |
| A-单卡压缩版 | 微星 B3WH + 自扩 64GB | RTX 5090D 32GB（单卡主机） | ~5.4 ~ 5.9 万 |
| B（省钱） | 微星 B3WH + 自扩 64GB | 二手 RTX 3090 24G ×2（48GB） | ~4.7 ~ 5.0 万 |
| A（放宽厚度） | Legion Pro 7i 5070 Ti（约 1.8 万，厚 2.6cm） | RTX 5090D 32GB（预留双卡位） | ~4.9 ~ 5.5 万 |

**显存是核心约束**：笔记本 12GB 起步（7B Q4 + BGE-M3 + reranker + KV ≈ 9~10GB），16GB 可上
14B 级（≈ 13GB）；30B-A3B Q4 需约 18GB，笔记本最高 24GB（5090）也只是勉强——生产级验证
以服务器为准：32GB 可跑 30B-A3B Q4 + RAG 全套，64GB（双卡）才能上 FP8 30B + 大 KV cache。

## 2. 笔记本（约 1.4 ~ 2.7 万，按「移动办公优先、64GB/2TB 硬约束」重排）

**硬约束**：厚度 ≤ 2.3cm（背包限制）+ 内存最终 64GB（32GB 不够）+ 硬盘 ≥ 2TB。
板载机型必须直接买到 64GB/2TB 版（买定离手），可扩机型到手自行加装。
显存分档（配合「轻量测试走笔记本、高需求算法走服务器」的分工）：

- **16GB**：可本地跑 14B Q4 + BGE-M3 + reranker + KV（约 13GB），与生产 30B 代差最小；
- **12GB**：可本地跑 7B Q4 + BGE 全套（约 9GB）——design.md §5.2 的路由分流/简单抽取
  正好是 7B 的角色，14B 及以上全部走服务器；预算最紧时可选。

- 笔记本终选（2026-08 锁定）：微星 Stealth 16 AI+ B3WH——唯一同时满足 U9 处理器、
  64GB 可自扩（双 SODIMM）、2TB 直给、5070 Ti、厚度 16.65~19.99mm 的香港官方渠道机型；

  本地小模型，生产级验证始终在 H20/服务器——首选 5070 Ti 路线，省下约 6000
  投服务器；若需本地跑 14B 级（升级触发条件）则上 5080；
- 5070 新 12GB 版（2026-04 发布，4×3GB GDDR7，128-bit 384 GB/s，与 8GB 版并存）：

  且厂商警告其定价可能逼近 5070 Ti——仅当比 5070 Ti 机型便宜 2000+ 才考虑；
  5070 旧 8GB 版：装不下 7B + BGE 全套，不买；
- 灵刃16（5080，约 2.6~3 万，售后弱）与枪神9 Plus（厚 3cm+）维持排除；
- 四品牌排查（2026-08）：联想 Y9000X 轻薄线顶配 5070 Ti 12GB（2026 款是否有 5080 待
  核实）、ThinkPad 全系 ≤12GB（P16 Gen 3 的 RTX Pro 3000）、Dell 轻薄线 ≤12GB
  （XPS/Premium 16）、Alienware 5080 机型厚 28mm+——**绝影16 AI+ 是这四家中唯一
  轻薄 + 5080 的组合**；
- 行情：上半年国补期间同档机型曾到 1.16 ~ 2.1 万档，8 月国补结束 + GDDR7 缺货全面
  回升；双 11 是下一个可能的折扣窗口。

**选购底线**：

- 显存 ≥ 12GB（首选 5070 Ti；16GB 升级触发条件见上）；厚度 ≤ 2.3cm；
- 内存最终 64GB（硬约束）+ 硬盘 ≥ 2TB：可扩机型到手加装（双 SODIMM + 双 M.2），
  板载机型必须直接买 64GB/2TB SKU；
- 不要 8GB 机型（5060 / 5070 旧 8GB 版：7B Q4 + BGE 全套约 9GB 装不下）；
  5070 新 12GB 版容量可用但带宽仅 384 GB/s，同价位优先 5070 Ti（672 GB/s）；
- RTX 5090 Laptop 24GB 顶配溢价过大，不推荐。

**已排除**：

- ROG 幻14 Air 全系：板载 32GB 封顶、无 64GB 档，不满足 64GB 硬约束（曾列为首选，已移除）；
- ThinkPad P16 Gen 3：中国区在售最高 RTX Pro 3000——与 5070 Ti 同芯片（GB205：
  5888 核 / 12GB / 192-bit / 672 GB/s），但 TGP 被限到 90/105W（性能损失 15~30%），
  且整机 3 万+、贵出同配置游戏本近一倍，ECC/ISV 对 AI 开发无价值，排除；

- ThinkPad P1 Gen 8：顶配 RTX Pro 2000（8GB GDDR7，128-bit 档），装不下 7B + BGE 全套
  （约 9~10GB），排除——轻薄工作站线至此全线出局（Pro 2000 8GB / Pro 3000 12GB 低功耗 /
  Pro 4000 超预算）；
- Dell Pro Max 16/18 Plus：16GB 显存版（RTX Pro 4000）4 万起，超预算；24GB 版 8 万级；
- Dell XPS / Dell Premium 16（XPS 后继）：轻薄设计本定位，独显上限 8GB（4070）~ 12GB 级别，
  TGP 仅 40~70W，达不到 16GB 底线且性能释放受限（具体顶配以 dell.com/zh-cn 配置器为准）；
- MacBook：无 NVIDIA GPU 跑不了 CUDA，vLLM/SGLang/TEI/nvidia-container-toolkit 全栈无法运行，
  本地验证结果与服务器（5090D/H20）无法对齐。
- 微星 Raider 16 MAX HX（175W 满血 5080 + 290HX Plus）：21.95~28.85mm / 2.6kg，超 2.3cm
  厚度约束，排除；
- ROG 幻16 Air 2026（GU606）：板载 LPDDR5X 不可扩，64GB 必须直接买 64G SKU；且起价比
  上代暴涨 50%+（港行 5070Ti/32G/1T = HK$31,998，5080/64G/2T 约 3.5 万 RMB，5090/64G/2T
  = HK$49,998），为凑 64GB 被迫上高配，性价比崩，排除；
- Dell Pro Precision 7 系列 16（PW716260）：GPU 天花板 RTX Pro 3000（12GB，无 16GB 档、
  无 GeForce），基础价 HK$46,798.60 且为核显版、选独显后约 5 万港币，重量未标（7 系列
  工作站历来 2.5kg+），性价比崩，排除——Dell 全线至此确认无解；

## 3. 服务器方案 A（推荐，约 3.1 ~ 3.7 万）

单卡 RTX 5090D 32GB，主板/电源/机箱预留第二张卡升级位。

| 部件 | 型号 | 参考价 |
|---|---|---|
| GPU | RTX 5090D 32GB（技嘉 WINDFORCE 官方价 16,499 难抢，渠道现货约 2 万） | 1.65 ~ 2.2 万 |
| CPU | R9 9950X 散片（16C32T） | ~2900 |
| 散热 | 360 一体水冷 | ~500 |
| 主板 | 华硕 ProArt X670E-Creator（双 PCIe 5.0 x8/x8，板载 10G + 2.5G 双网口） | 3500 ~ 5000 |
| 内存 | 96GB DDR5（2×48GB，留 2 槽以后扩 192GB） | ~2600 |
| 硬盘 | 1TB 系统盘 + 4TB 数据盘（PCIe4，如致态 TiPlus7100） | ~2800 |
| 电源 | 1600W ATX 3.1（为第二张 5090D 预留） | 1600 ~ 2000 |
| 机箱 | 全塔（联力 Lancool III 级别，能装两张三槽卡） | ~700 |

若确定永远单卡（A-单卡压缩版，整机约 2.5 ~ 3.0 万）：CPU 换 9900X（~2200）、主板换
B650E（~1400）、内存 64GB（~1400）、硬盘 1TB + 2TB（~1500）、电源 1200W（~900），
比全配省约 6000 元，但放弃双卡升级路径。

**显存账**：32GB = 30B-A3B Q4（18GB）+ BGE-M3 + reranker-v2-m3（5GB）+ KV cache，单卡同时
跑推理 + RAG 全套；vLLM 起 OpenAI 兼容端点后，网关配置与连 H20 完全同构，只换 base_url。

**升级路径**：卡价回落后加第二张 5090D → 64GB 显存，可跑 FP8 30B + 大 KV cache。
注意双卡满载约 1500W+，届时需要 16A 空调插座或限制功耗。

## 6. 到货后初始化清单

服务器（Ubuntu 24.04 LTS）：

- Docker + nvidia-container-toolkit；
- vLLM/SGLang 起 OpenAI 兼容端点（对应 `design.md` §5.3 网关），TEI 起 BGE-M3/reranker（§5.4）；
- Compose 栈：fastagent-api + qdrant + tei + postgres + langfuse + Blazor 前端（§10）；
- code-server / VS Code Remote-SSH 远程开发；
- 入公司内网，与三平台 MySQL 同网段；
- 办公室环境 `nvidia-smi` 限 450W 控制噪音（推理吞吐损失约一成）；单卡满载整机约 900W，
