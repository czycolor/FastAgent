二、需求與硬約束

  • 用途：FastAgent 企業 Agent 平台的開發機——ASP.NET Core Blazor Web 開發＋本地部署小模型推理（不訓練，訓練走伺服器）；高需求算法全部走伺服器（32GB 級顯存）與公司 H20；Revit 二次開發在 Windows 原生支持。
  • 處理器：Intel Core Ultra 9（U9 級）
  • 記憶體：最終 64GB（官網無合適配置時，必須支援自行擴展）
  • 硬碟：≥ 2TB（可直給，或雙 M.2 自加）
  • 顯示卡：RTX 5070 Ti 12GB 或 RTX 5080 16GB（8GB 機型一票否決：裝不下 7B Q4 + BGE 全套約 9~10GB）
  • 厚度：2cm 左右，不能太厚（背包限制）
  • 採購渠道：香港（官方商城／街頭）；伺服器公司指定 Dell 品牌優先，備有非 Dell 替代路線

六、搭配建議與注意事項

  • 總預算：手提電腦（首選 MSI B3WH ≈ 2.9 萬 RMB）＋ Dell T2（128GB + 4TB + Pro 5000 48GB，HK$9.0~10.0 萬 ≈ 8.3~9.2 萬 RMB）≈ 11.2 ~ 12.1 萬 RMB；若伺服器改選自組 5090D（≈3.1~3.7 萬 RMB），合計 ≈ 6.0 ~ 6.6 萬 RMB
  • 購買順序：顯示卡先下單（5090D 在漲價通道／Dell Pro 4500 加價未公開，先鎖卡價）→ 手提電腦下單 → 加裝件（記憶體／硬碟）
  • 保養：港行在大陸使用的跨境保養政策，下單前確認（MSI／華碩／HP／Dell 均需確認）
  • 顯存帳：30B-A3B Q4（約 18GB）＋ BGE 全套（5GB）＋ KV ≈ 23GB——伺服器 24GB 起、32GB 從容、48GB 可上 FP8、72GB 可跑 70B Q4；手提電腦：12GB 跑 7B 級（約 9~10GB）、16GB 上 14B 級
